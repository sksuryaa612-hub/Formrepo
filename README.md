# 📋 Student Registration Form

A simple and beginner-friendly Student Registration Form built using HTML and CSS.

This project allows users to enter their details through a registration form and displays sample student information in a table.

---

## 🚀 Features

- 👤 Full Name Input
- 📧 Email Input
- 🔒 Password Field
- 🚻 Gender Selection
- 💻 Skills Selection
- 📅 Date of Birth Input
- ✅ Form Validation using `required`
- 🎨 CSS Styling
- ✨ Hover Effects
- 📊 Submitted Students Dummy Data Table

---

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3

---

## 📚 Learning Outcomes

This project helps in understanding:

- HTML Forms
- Input Validation
- Tables in HTML
- CSS Styling
- Universal Selector
- Hover Effects
- Responsive Layout Basics

---

## 🎯 Project Purpose

The purpose of this project is to practice creating forms, applying CSS styles, and building a clean and user-friendly web page.
